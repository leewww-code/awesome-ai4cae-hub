研究路线

求解器耦合的优化与校正流水线

将学习型代理嵌入基于 CFD 的设计循环，利用不确定性或求解器反馈提升可靠性与优化速度。

尚未覆盖：外部验证仍限于内部车辆数据集或特定翼型；超出已有几何族和流动区间的部署可靠性尚未证明。
几何条件化神经代理服务

从几何和运行条件快速预测气动场和系数，用于交互式或高通量分析。

尚未覆盖：精度、计算成本和对新运行点/网格/车辆类别的鲁棒性仍需权衡；当前证据覆盖的气动范围较窄。
智能体分析与工具链

通过 LLM 驱动工作流自动化多步流场分解、可视化、物理解释和建模建议。

尚未覆盖：除五个基准外可复现性和一致性未知；代码与工件信号有限，自主行为未在外部部署中检验。
高保真气动数据集与基准工件

提供标准化 CFD 数据和受控评测划分，用于比较代理架构并暴露分布偏移弱点。

尚未覆盖：覆盖局限于选定几何与流动状态；即使强分布内模型在运行点、网格离散化和跨车型偏移下也会退化。

研究共性

  • CFD 生成的数据与物理信息校正或验证，是构建可信气动代理模型的核心基础。
  • 神经代理相对传统 CFD 能带来显著加速，但仅凭高精度不足以证明可靠性。
  • 评测正从单一几何插值走向多工况基准、受控分布偏移和有限的物理/风洞校验。
  • 工作流越来越多将代理嵌入更大系统：优化循环、求解器校正、智能体推理和可复用工件。

关键差异

  • 一些系统侧重快速独立预测，而另一些系统则消耗额外求解器或智能体计算来强制物理一致性。
  • 表示方式存在差异：谱几何条件化、点云状态注意力以及图/算子建模并存。
  • 评测目标不同：从气动场预测、车辆减阻优化到湍流分量发现和架构基准评测。
  • 部署场景不同：从稳态二维不可压缩翼型流动到跨音速优化、工业三维飞机和高保真皮卡气动。

开放问题

  • 这些系统在报告几何族、运行点和内部数据集之外能否保持泛化？
  • 当不同方法报告的计算成本结果不一致时，交互或实时部署可接受的精度-延迟-计算边界是什么？
  • 在代码和工件证据较弱的情况下，智能体与求解器耦合工作流能否被独立复现？
  • 哪些建模选择或数据偏差导致运行点、网格离散化和跨车型分布偏移下的显著退化？

研究路线

物理与几何条件化代理表示

将物理先验转化为具体的几何/流动编码器、神经场、注意力、图或随机可分离目标，用于压力/速度/流场预测。

尚未覆盖：哪些表示选择能跨出稳态二维不可压缩NACA翼型等窄场景；S$^{2}$-PINN在证据包中只有标题，无法评估其假设。
智能体与工具接口科学工作流

将领域知识或流场分解接入LLM规划、确定性工具执行、多智能体审查和本体约束的分析链。

尚未覆盖：收益归属未解决：可能来自本体/工具封装、规划器或LLM；战略错误仍存在，本体示例仅在两个域中验证。
方法证据与消融基准协议

通过架构基准、消融、泛化切分和适应基准，分离方法贡献与数据集、基线、指标和实现影响。

尚未覆盖：证据包中若干记录缺少代码、数据、显式限制或分析文本；PACE-Bench与重复FSAN记录不足以验证方法贡献被隔离。

研究共性

  • 结构化分离常见：几何、流动状态、物理约束或领域事实被分别编码，再通过可学习或规则层组合。
  • 评估集中在气动场预测、湍流分析或工具中介分析等科学/工程任务，采用精度、相对误差、基准性能或工作流正确性。
  • 方法贡献被视为条件于检索、条件化或基准选择；消融和对比研究用于隔离部分设计因素。

关键差异

  • 表示不同：连续代理模型使用神经场、神经ODE、图模型、注意力或随机PINN类目标，智能体工作流使用LLM加确定性工具、本体或多智能体审查。
  • 监督与评测目标不同：场误差、解释/工具选择正确性、架构扩展与激波捕捉、动态代码适应各有侧重。
  • 交互方式不同：单步代理推理与多步工具编排和迭代一致性审查。
  • 部署假设不同：部分方法在稳态二维不可压缩NACA或汽车流中评测，部分面向三维飞行器或跨域工具扩展，因此泛化结论受场景约束。

开放问题

  • 报告中的场误差降低有多少来自表示或注意力选择，而非基准特定的几何-流动结构与训练数据？
  • 基于本体和智能体的工作流在无法范围化检索或离开CFD与拓扑工具封装时，是否仍能保持正确？
  • 随机可分离PINN和物理适应基准等低证据方法在证据包中缺少代码、数据或分析细节，是否可复现？
  • 当前气动代理模型能否从稳态二维不可压缩NACA域扩展到瞬态、可压缩、三维工业场景，而不依赖窄域数据先验？

benchmark

数据集、评测任务、指标和基准测试

52 方法质量 98 近期性 36 可复现性 11 主题相关性

文献综述归纳

研究路线

气动基准任务与数据集设计

构建共享CFD任务和参考数据集，使翼型、机翼、车辆和飞行器配置上的神经代理模型评测可比。

尚未覆盖：真实运行设置与分布偏移覆盖不足；强分布内结果不保证泛化。
气动代理模型的指标与压力测试设计

检验精度、力秩相关、求解器残差、加速比，以及在OOD几何、运行点、网格化和跨车型偏移下的鲁棒性。

尚未覆盖：代理指标与下游设计决策之间的对应关系，以及显式局限性证据。
可比基线与报告规范

用报告场误差指标、秩相关和加速比，将各架构与强基线比较，并部分提供数据集或求解器工件。

尚未覆盖：基准结论在不同实现和算力预算下的稳定性；代码、数据集和局限性报告不一致。

研究共性

  • 神经气动代理模型通常以共享CFD数据集上的Relative L2或MSE误差作为核心，并与强基线比较。
  • 泛化被视作重要评测维度，常用分布外几何、运行条件或求解器耦合进行检验。
  • 仅有高分布内精度不足以保证泛化；分布偏移测试会暴露速度依赖、网格划分和跨车型迁移问题。
  • 可复现性证据不均衡：基线和指标常被报告，但代码、数据集和显式局限性说明经常缺失或不完整；这属于核验缺口，而非证明工件不存在。

关键差异

  • 表示方式不同：有的模型用流态注意力编码点云几何，有的用谱编码器和域路由，有的采用LLM智能体或求解器耦合工作流。
  • 评测目标不同：表面压力、速度场MSE、气动力秩相关、残差比、雷诺应力预测和加速比被不同论文使用，缺少统一主要指标。
  • 泛化测试强度不同：专门的基准工作引入受控运行点、网格化和跨车型偏移，而架构导向评测常依赖已有数据集，未报告可比压力测试。
  • 部署场景不同：纯代理推理、求解器耦合校正、智能体物理发现和数据集发布对应不同的成功标准和可复现性预期。

开放问题

  • 基准分布能否扩展以覆盖真实气动设计中的几何、运行点和物理区域多样性？
  • 场误差、力秩相关、残差下降和加速比等代理指标中，哪些最能代表下游设计收益？
  • 在代码、数据集工件和局限性报告不一致的情况下，基准排名是否跨实现和算力预算稳定？
  • 如何在不牺牲当前基准分布内精度提升的同时，提高分布偏移鲁棒性？

application

面向具体工程场景的应用研究（翼型/机翼/叶轮/整车等）

研究路线

几何条件化气动代理模型

从几何编码快速预测翼型周围压力和速度场，减少CFD计算时间并保留气动特征。

尚未覆盖：证据限于稳态不可压缩二维亚音速流动和下压力型NACA 4-digit翼型；三维、可压缩、分离流泛化未显示。
气动算子学习评测

在二维翼型和工业级三维飞机表面压力上系统评测深度算子架构，覆盖激波捕捉、可扩展性和数据稀缺。

尚未覆盖：证据包缺少明确局限和真实飞行验证，结论可能限于被评测的架构与气动案例。
多精度与维度桥接RANS回归

从低维RANS模型向高维气动系数代理学习修正，结合不确定性量化和神经网络加速核实现实时估计。

尚未覆盖：性能依赖低维模型选择；神经网络加速核是近似，更广精度跨度未测试。
物理信息与无数据Navier-Stokes代理

无需外部流场数据，通过物理残差求解低雷诺数到高雷诺数的稳态Navier-Stokes基准问题。

尚未覆盖：证据多集中在稳态基准；未给出非定常或工程尺度湍流的详细限制分析。

研究共性

  • 学习型代理被视为CFD的更便宜替代或加速器，用于工程气动和流动预测。
  • 论文共同关注工程相关输出，如压力、速度、气动系数、激波、湍流尾流或不确定性，而不是通用图像重建。
  • 公开数据集、基线比较和可复现工件正在成为重要贡献。
  • 泛化通过几何插值/外推、数据稀缺、规模扩展或自适应采样来检验，但不统一。

关键差异

  • 监督信号不同：有的用高精度仿真标签，有的用物理残差，有的学习低到高精度修正。
  • 表示方式不同：谱几何编码、算子/图网络、四叉树分词Transformer、高斯泛函回归和浅层循环解码器各自用于不同工作。
  • 评测目标不同：有的预测表面场，有的预测积分气动系数，有的预测湍流通道/尾流，有的做稀疏传感重建。
  • 部署场景不同：离线代理加速、实时神经网络核评估、无数据PDE求解和稀疏传感诊断重建并存。

开放问题

  • 几何条件化气动代理能否扩展到三维、可压缩、高雷诺分离流，而不只是报告的NACA 4-digit下压力案例？
  • 被评测算子架构在工业飞机场景中的明确失效边界是什么，尤其在激波和少量数据下？
  • 如何为决策级不确定性量化验证低维模型选择和神经网络核近似？
  • 物理信息无数据和自适应PDE预测方法能否扩展到工程相关湍流配置？
  • 稀疏传感重建在真实气动或叶轮机械监测中的鲁棒性是否足够？

研究路线

希尔伯特空间泛函生成传输

在函数空间上匹配流以生成湍流场，避免只在有限维样本空间建模。

尚未覆盖：有限样本与离散化误差界，以及最优传输引导在湍流场景之外的适用性。
保结构PDE离散与热启动

通过度量依赖的平衡态和强迫项在非均匀聚簇网格上高效模拟Navier-Stokes流动，或利用机器学习为PDE求解器提供热启动。

尚未覆盖：复杂几何、高雷诺数下的误差与收敛行为，以及学习热启动与求解器收敛的交互。
谱与秩结构估计

通过层次秩正则化降低高维协方差估计的采样误差；随机自适应傅里叶分解为算子学习提供谱基。

尚未覆盖：秩和谱假设是否跨数据成立，以及报告场景之外的误差界验证。
非定常气动解析一致性条件

用递推关系重整附着涡片强度，保证涡片连续和后缘零载荷。

尚未覆盖：薄翼/Wagner设定之外的扩展，以及更广泛非定常流数据的验证。

研究共性

  • 研究普遍倾向于在模型或数值方法中嵌入数学结构，如传输、坐标度量、谱基、秩约束、递推关系或动理学方程，而不是依赖无约束黑箱拟合。
  • 现有证据主要以推导为主，实验验证、基线、指标、代码和数据集大多缺失或在数据包中不可见。
  • 共同目标是提升连续场和算子相关问题的物理一致性、数值效率或统计可靠性。

关键差异

  • 表示方式不同：连续Hilbert空间流、正交坐标Lattice Boltzmann、随机谱分解、层次协方差因子、涡片递推、自编码器潜空间和动理学智能体动力学。
  • 评测目标不同：湍流场生成、PDE流动模拟、算子学习、协方差估计、非定常翼载荷、潜物理组织和智能体动力学。
  • 假设策略不同：有些工作严格施加物理约束，有些则从气动或PDE数据中学习结构，形式保证较弱。

开放问题

  • 推导出的相容性条件能否从正交坐标或薄翼几何推广到复杂不规则区域和强非线性流动？
  • Hilbert空间流匹配能否在有限训练样本和离散化下建立误差与收敛界？
  • 层次秩或自适应谱假设在CFD/地学示例之外是否仍然成立？
  • 自编码器的物理组织潜结构能否转化为可验证的预测误差或求解器改进？
  • 自演化智能体的动理学理论能否预测实际学习系统的稳定性和失效模式？
