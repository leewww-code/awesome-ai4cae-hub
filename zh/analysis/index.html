研究路线

端到端代理优化与求解器耦合工作流

把学习到的气动预测转化为设计循环或 CFD 初值，使下游任务在保持数值可靠性的同时获得代理加速。

尚未覆盖：外部部署证据较窄；形状优化主要在内部车辆数据集上验证，部分论文未报告局限。
几何条件化流场代理服务

从几何和运行条件快速预测压力、速度或阻力，相较常规 CFD 提供数量级加速。

尚未覆盖：精度与计算成本权衡仍存在；对未见几何、速度条件和非训练翼型族的泛化仅得到部分测试。
高保真基准与数据集工程

在受控分布偏移下标准化评估代理架构，包括运行点、网格划分和跨车型迁移。

尚未覆盖：不同架构鲁棒性差异明显，未证明存在统一鲁棒代理；工件的独立使用与长期维护尚未得到证实。
面向物理发现的智能体分析框架

通过 LLM 驱动的多智能体推理自动化流动分解、模式解释与湍流模型建议。

尚未覆盖：可复现信号较弱，缺少局限性说明，与工业求解器管线的集成尚未验证。

研究共性

  • 学习代理能在多个设置下相对常规 CFD 显著加速气动预测与优化。
  • 基准数据集与分布偏移评估显示，代理在分布内表现强并不代表对运行条件、网格划分和跨车型变化具有鲁棒性。
  • 求解器耦合或物理反馈被视为提升可靠性的手段，如不确定性触发反馈、Newton-Krylov 校正或 CFD 验证。
  • 智能体和自动化工作流可以产生物理相关建议，但可见证据尚未确立独立可复现性或广泛工业部署。

关键差异

  • 表示选择不同：点云流态注意力、谱几何编码、Mixture-of-Experts 神经算子和求解器耦合 Newton 校正采用不同的几何与流动编码方式。
  • 评测目标不同：二维 NACA 翼型、工业级三维飞机、皮卡、跨音速翼型优化和周期性山丘湍流分别考验激波、分离或钝体尾流等现象。
  • 交互模式不同：部分系统是离线预测器，其他系统采用不确定性触发求解器反馈、求解器耦合校正或自主 LLM 推理闭环。
  • 部署假设不同：一些研究依赖内部车辆数据集，另一些提供公开基准，因此外部有效性和鲁棒性结论难以直接比较。

  • 证据包中缺失的代码、数据集、基线和局限性细节构成哪些验证缺口？

method

新模型、算法、训练或推理方法

37 方法质量 87 近期性 36 可复现性 10 主题相关性

文献综述归纳

研究路线

几何与流动条件驱动的神经代理方法

学习从几何/流动条件到连续气动场的快速映射；如 Airfoil2Vec 的谱几何条件、FSAN 的流状态注意力，以及算子学习架构比较。

尚未覆盖：可见成功主要限于稳态亚音速或不可压缩翼型/飞行器案例；可压缩、非定常或非气动场景的泛化与精度-成本权衡仍未解决。
物理信息与结构化参数化方法

将随机、可分离或物理特定结构注入神经 PDE 求解器；唯一可见示例是 S$^{2}$-PINN，本数据包中仅为标题级证据。

尚未覆盖：缺少可见的摘要、实验、基线、指标与局限，因此无法从本证据评估其贡献和可迁移性。
LLM 智能体与领域锚定的编排方法

将意图理解、确定性工具执行、解释或物理发现分离并自动化；示例包括领域锚定工具编排和 PhysMiner 三重分解智能体。

尚未覆盖：策略性错误仍存在；本体收益依赖 scoped retrieval；可见验证限于两个领域或五个基准；PhysMiner 局限与更广泛通用性未确立。
方法评估与适应性基准

比较面向气动预测的算子学习架构，并评估动态环境下通过代码演化进行物理适应；示例包括 PACE-Bench 与架构评估。

尚未覆盖：PACE-Bench 可见证据稀疏，架构评估未给出明确局限；指标隔离、复现工件与迁移性仍待验证。

研究共性

  • 在方法细节可见的工作中，方法将领域特定结构与学习组件结合，而非仅依赖通用端到端预测器。
  • 证据模式倾向于通过消融或受控基准比较来证明方法效果。
  • 当前主流应用集中在气动代理建模与科学分析工作流，目标多为传统 CFD 加速或分析自动化。
  • 多个工作将领域先验作为约束或纠正机制，而不是事后标签。

关键差异

  • 表示方式不同：连续谱或流状态神经表示、本体/工具图、基于分解与推理的 LLM 智能体流水线。
  • 评测目标不同：场级气动误差、LLM 解释/工具选择准确率、湍流建模建议、跨架构基准排名。
  • 部署交互不同：面向快速推理的神经代理，对比需要确定性工具和 LLM 推理的智能体系统。
  • 成本/精度权衡不同：部分方法报告精度提升但计算成本更高，部分工作强调相对于传统 CFD 的数量级加速。

开放问题

  • 气动代理结论能否从稳态、亚音速、以 NACA 4-digit/汽车翼型为主的场景迁移到更广泛物理场景？
  • 本体/工具 grounding 能否在两个报告领域之外泛化，scoped retrieval 是否始终必要？
  • 报告提升中有多少来自所提出的架构，而非数据集规模、基础模型、训练协议或工具封装质量？
  • 流状态注意力或智能体推理能否在计算受限或生产规模部署下保持精度？
  • 填补 S$^{2}$-PINN、PACE-Bench、PhysMiner 等条目的局限与复现信息会如何改变结论？

benchmark

数据集、评测任务、指标和基准测试

52 方法质量 98 近期性 36 可复现性 11 主题相关性

文献综述归纳

研究路线

基准任务与数据集设计

构建共享高保真气动任务和数据集，使神经代理在不同几何与运行条件下可比；例如 SHIFT-Truck 和多架构气动基准。

尚未覆盖：任务分布是否覆盖开放式货厢、工业飞机配置和更广泛车辆类别；现有证据集中于少量典型和车辆特定设置。
指标与压力测试设计

在总分之外检验预测质量，包括相对 L2 误差、速度场 MSE、阻力秩相关、残差比，以及雷诺数、运行点、网格划分和跨车辆等分布偏移协议。

尚未覆盖：这些代理指标与下游决策（如设计优化收敛、求解器可靠性、物理发现效用）是否一致仍缺乏证据。
可比基线与报告规范

通过共同基线、基线相对改进、消融以及部分求解器加速或架构鲁棒性报告，让代理结果可审计。

尚未覆盖：top 证据中多篇论文缺少明确局限性、代码、数据集或工件信息；结论在不同实现、算力预算和缺失复现信息下是否稳定未知。

研究共性

  • 气动/计算流体动力学的代理论文在 AirfRANS、Emmi-Wing、DrivAerNet++ 及高保真仿真数据集等共享设置上聚合。
  • 相对 L2 误差、速度/压力 MSE 等场误差指标被广泛报告，常辅以力误差或秩相关指标来刻画积分气动量。
  • 分布偏移被视为一等评估条件，尤其是雷诺数外推、运行条件变化、网格划分和跨车辆形状迁移。
  • 论文普遍认为仅凭分布内精度不足以证明泛化能力或工程实用性。

关键差异

  • 表示选择不同：流态注意力、域分解路由与学习积分、物理信息随机可分离表示、LLM 智能体推理。
  • 评测目标不同：有的针对表面压力或速度场，有的针对力预测、求解器残差校正或自动化湍流组分发现。
  • 鲁棒性评估不统一：协议包括雷诺数外推、运行点偏移、输入网格划分变化和跨车辆迁移，部分论文未报告明确局限性。
  • 计算代价权衡判断不同：一种方法以更高算力换精度，另一种报告求解器级加速；基准对是否把代价纳入比较不一致。

开放问题

  • 当前基准任务分布是否覆盖真实部署设置，而不仅是现有翼型、机翼、SUV、皮卡和飞机案例？
  • 相对 L2、场 MSE 和阻力秩相关是否足以作为下游工程决策（如优化收敛和求解器可靠性）的代理指标？
  • 当代码或数据集工件在证据包中不可见时，不同实现、训练预算和推理算力下报告排名是否稳定？
  • 仅靠代理评测协议能否捕捉求解器耦合校正或智能体物理发现带来的可靠性，而无需共享数值收敛判据？

研究路线

几何条件化气动场代理建模

从几何出发预测翼型周围压力/速度场，取得显著CFD加速。

尚未覆盖：证据限于稳态不可压缩二维亚音速与下压力NACA 4-digit翼型；非NACA、三维、瞬态泛化未验证。
面向工业压力预测的算子学习架构评测

在二维翼型和三维飞机上比较神经算子架构在激波、可扩展性与数据稀缺下的表面压力预测。

尚未覆盖：摘要未给明确局限；可复现信号弱，更广工程验证缺失。
多保真维度桥接RANS回归

学习二维到三维RANS修正以预测气动系数，并提供不确定性驱动采样和快速核评估。

尚未覆盖：性能依赖低维模型选择；神经网络加速核可能用精度换速度。
物理信息无数据Navier-Stokes求解

无需外部流动数据求解低至高雷诺数稳态Navier-Stokes基准问题。

尚未覆盖：分析证据为空；复杂几何、瞬态和工程相关校验缺少记录。

研究共性

  • 学习代理被定位为CFD/RANS的快速替代，同时保持可接受的气动精度。
  • 几何或流动条件编码被视为气动预测所需。
  • 数据集和基准用于架构比较，而不仅是单个模型性能报告。
  • 速度、精度和泛化权衡受到关注，但验证协议不一致。

关键差异

  • 表示选择不同：神经场/ODE、MLP/GNN、Transformer 与高斯泛函回归。
  • 训练信号不同：RANS/LBM仿真数据监督、无数据物理残差、多保真修正。
  • 预测目标不同：全场压力/速度、仅表面压力、积分气动系数、PDE状态。
  • 评测设置不同：二维稳态翼型、工业三维飞机、湍流三维通道、自适应网格PDE。
  • 不确定性处理不同：高斯回归中用于自适应采样，多个代理基准中未说明或缺失。

研究路线

泛函生成与算子学习形式化

构建随机、Fourier或流匹配表示，在连续或Hilbert空间中对PDE与场数据进行生成或代理建模。

尚未覆盖：有限样本与真实湍流/算子数据下的收敛与误差界；与标准求解器和基线的实证比较在数据包中缺失。
数值PDE形式化与网格/求解器加速

在非均匀聚簇网格上重构Navier-Stokes或Lattice Boltzmann求解形式，或使用任意维机器学习热启动PDE求解器。

尚未覆盖：在已展示网格或求解器条件之外的稳定性、精度与收敛性保证；缺少代码和基准细节，难以独立验证。
层级/低秩协方差与潜结构估计

通过层级秩、低秩或物理结构正则化，从少量样本估计高维协方差矩阵，或组织空气动力学潜空间。

尚未覆盖：估计不确定性与潜空间组织是否能迁移到地球科学、空气动力学或数据稀缺场景之外，缺少直接概率校准证据。
非定常或智能体模型中的物理一致性

导出差分递推或动理学理论，强加涡片连续性、后缘零载荷或门控自演化等一致性条件。

尚未覆盖：与高保真模拟或实验的对比有限；假设在非线性、多智能体或复杂流场中的适用性尚未验证。

研究共性

  • 论文共享一个假设：将物理或数学结构嵌入模型或估计器，可相对非结构化方法改善一致性、稳定性或样本效率。
  • 理论推导通常与数值仿真或算法开发结合，而非仅作解析声明；流体、PDE或CFD类场景是常见验证域。
  • 多数工作强调表示层面的结构，如一致收敛、物理一致性、层级/低秩约束或Hilbert空间形式，而不只是经验基准提升。

关键差异

  • 表示对象不同：函数空间生成场、算子代理、坐标变换PDE求解器、协方差矩阵、潜空间以及降阶涡/智能体模型。
  • 监督与评测目标不同：部分追求收敛性或一致性推导，部分以重建质量、仿真效率或空气动力学数据库的潜空间组织为主。
  • 部署场景不同：高维湍流/地球科学数据、经典薄翼或Navier-Stokes求解器、自演化LLM智能体动力学对假设和评测约束不同。
  • 结构先验不同：最优传输/流匹配、度量相关Lattice Boltzmann项、层级秩正则、涡片连续性和动理学门控是不同机制。
