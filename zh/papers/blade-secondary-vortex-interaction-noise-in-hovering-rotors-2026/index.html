深度分析

创新点

  • 识别出叶片二次涡干涉（blade secondary vortex interaction, BSVI）是悬停旋翼中一种独特且此前未被表征的非周期音调噪声来源。
  • 表明由尾迹剪切层卷入前序叶片主 tip vortices 形成的相干 S 形二次涡结构（secondary vortex worms），会撞击外侧叶片段（r/R ≈ 0.88–0.96），并产生叶片间相关载荷。
  • 使用 spectral proper orthogonal decomposition 将中频（3–10 kHz）低秩相干模态（与 braids 相关）和较低频（约 1 kHz）模态（与主 tip vortex core 相关）分离。
  • 证实测得的高次谐波叶片通过频率音调源自旋翼流动本身，而非封闭腔体测试环境。

方法

该研究采用混合 Reynolds-averaged Navier-Stokes/large-eddy simulations 耦合 Ffowcs Williams-Hawkings 声类比，对悬停状态下的四叶片理想扭转旋翼进行模拟。将模拟远场频谱与室内测量结果对比，并通过流场分析以及对零均值上洗速度的 spectral proper orthogonal decomposition，将噪声与涡结构关联。

关键结果

模拟复现了测得的高次谐波叶片通过频率音调，证实其源自旋翼流动。流场与 spectral proper orthogonal decomposition 分析将这些音调归因于叶片二次涡干涉：中频 3–10 kHz 成分由与 braids 相关的单一低秩模态主导，而约 1 kHz 的较低频模态与主 tip vortex core 相关。

局限性

  • 研究仅限于悬停状态下的四叶片理想扭转旋翼；摘要未涉及其他旋翼构型和飞行条件。
