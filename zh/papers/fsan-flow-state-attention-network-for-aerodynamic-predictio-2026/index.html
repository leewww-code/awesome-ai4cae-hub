深度分析

创新点

  • 提出 Flow State Attention Network (FSAN)，分别编码点云几何与流动条件，而非将所有表面点统一注入单一全局流动向量。
  • 引入可学习的软分配，将几何划分为多个流动状态，使流动特征更新状态表示，并通过状态变化影响点云特征。
  • 实现几何与流动信息之间细粒度、状态特定的交互，以提升复杂流动条件下的预测性能。

方法

FSAN 分别编码点云和流动条件，然后通过可学习的软分配将几何划分为多个流动状态。流动特征更新这些状态表示，状态表示再通过状态变化影响点云特征。该方法在 Emmi-Wing 和 DrivAerNet++ 上，以 Relative L2 误差为指标，与包括 Transolver 和 AdaField 在内的基线进行评估。

关键结果

FSAN 在比较方法中取得了最高精度；在 Emmi-Wing 上，相较最强基线 Transolver，REL-L2 误差降低超过 20%；在 DrivAerNet++ 上，相较最强基线 AdaField，误差降低 10%。

局限性

  • FSAN 以高于所比较方法的计算成本实现其精度。
