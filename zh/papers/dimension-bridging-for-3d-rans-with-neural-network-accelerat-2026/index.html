深度分析

创新点

  • 将 Gaussian Functional Regression 应用于学习从 2D RANS 模型到 3D RANS 模型的修正，以预测气动系数，桥接控制物理中的维度差异。
  • 提出一种维度桥接核，使响应面回归在与标准平稳核相同精度下可使用更少的高维评估。
  • 更具信息量的不确定性量化，可改进自适应采样。
  • 一种神经网络加速核，在墙钟时间测量中将评估速度提升数百万倍，使计算进入实时范围。

方法

作者使用 Gaussian Functional Regression 学习对 2D RANS 模型的修正，使其能够预测来自 3D RANS 模型的气动系数。他们引入针对 2D 到 3D 维度差异定制的核，与标准平稳核进行比较，利用不确定性量化驱动自适应采样，并提出一种神经网络加速核以实现更快评估。

关键结果

在适当选择低维模型时，所提出的核需要更少的高维评估即可达到与标准平稳核相同的精度，并为自适应采样提供更具信息量的不确定性量化。神经网络加速核在保持良好一致性的同时，将墙钟时间测量中的评估速度提升数百万倍。

局限性

  • 所提出核的有效性取决于低维模型的适当选择。
  • 除条件性性能以及神经网络加速核的近似一致性外，标题或摘要未明确陈述其他限制。
