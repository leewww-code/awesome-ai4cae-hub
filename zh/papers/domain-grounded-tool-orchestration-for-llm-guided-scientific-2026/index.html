深度分析

创新点

  • 将意图解释（LLM）、执行（确定性领域工具）与解释（LLM）分离，并通过 Model Context Protocol (MCP) 连接。
  • 领域本体将规划约束到有效分析链，为工具编排提供 grounding。
  • 该设计从构造上消除整类失败，如 API 幻觉和缺失流水线阶段。
  • 可扩展架构：添加第二个领域仅需本体和工具封装，无需修改架构、协议或部署。
  • 通过消融隔离本体作用：它提升的是解释准确率而非工具选择，且仅在限定范围的事实检索时有效。
  • ParaView 客户端-服务器部署通过轻量浏览器客户端将分析扩展到生产规模数据集。

方法

论文提出一种架构，将基于 LLM 的意图解释、确定性领域工具执行和 LLM 解释解耦，并通过 Model Context Protocol 连接，由约束规划的领域本体提供 grounding。该架构在 CFD 后处理和基于 TTK 的拓扑数据分析两个领域中，基于同一 ParaView 服务器基础设施进行实例化。跨两个领域的消融实验评估工具选择和解释准确率，包括本体事实的限定范围检索与批量检索对比。

关键结果

跨两个领域的消融实验表明，本体不改变规划器选择哪些工具，但将解释准确率从 0.41 提升到 0.91，且仅在相关事实以限定范围而非批量形式检索时如此。添加第二个领域只需围绕现有滤波器提供本体和工具封装，无需修改架构、协议或部署。

局限性

  • 该设计缩小了战略性错误，但并未完全消除。
  • 本体对解释的纠正效果以限定范围检索相关事实为条件；批量检索不会带来同样收益。
  • 所报告的实例化仅覆盖两个领域，因此摘要中未确立更广泛的泛化性。
