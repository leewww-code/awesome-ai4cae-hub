深度分析

创新点

  • 面向CFD中编码智能体的案例包操作模型，包含两种模式：Build用于在工程审查下进行智能体辅助案例开发，Replay用于将已审查案例应用于新变体。
  • 持久、可审查的案例包，打包仿真配置、几何处理与网格划分流程、远程执行脚本、后处理代码以及审查记录。
  • 在可复用CFD工作流中，将常规执行自动化与工程判断分离。

方法

该模型应用于OpenFOAM-7 interFoam喷油器设计筛选研究。Codex中的GPT-5.5协助开发了一个经过审查的案例包，随后通过重放该案例包，在远程高性能计算系统上执行并后处理140个STL几何变体。另一项单独的重放练习使用Pi coding agent作为运行时，并搭配四种不同的LLM后端。

关键结果

经过审查的案例包被重放，以在远程HPC上执行并后处理140个STL几何变体。所有四次使用不同LLM后端的Pi coding agent运行均成功并产生了验证结果，但不同运行之间的工具使用和token消耗存在差异。
