深度分析

创新点

  • 基准评测四种面向气动代理建模的最先进算子学习架构。
  • 评估在不同复杂度二维翼型及工业级三维飞机配置上的表面压力分布预测。
  • 评估模型在激波/间断捕捉、对大量网格点的可扩展性以及数据稀缺情况下的性能。
  • 指出 Bi-Stride Multi-Scale Graph Neural Network 与 Transolver(++) 是有前景的气动应用架构。

方法

对四种最先进算子学习模型在气动表面压力预测上进行基准评测。评估包含两项实验：不同复杂度的二维翼型，以及工业级三维飞机配置。模型在激波捕捉、对海量网格点的扩展能力以及数据稀缺处理方面接受评估。

关键结果

该基准评测表明 Bi-Stride Multi-Scale Graph Neural Network 与 Transolver(++) 是有前景的气动应用代理模型。分析就各架构在所评估需求上的优势与不足提供了详细洞见。
